# ChemHOT 行业配置

这个目录把通用热点框架配置为“化工现货与期货”行业站。

重点关注：
- 化工现货价格、装置、库存、开工、进出口与产业链供需；
- 化工企业采购、求购、招标、供应、扩产与项目商机；
- 期货公司的能源化工日报、周报、专题和策略研究；
- 交易所规则、仓单、交割、保证金与监管变化；
- 原油、OPEC、战争、制裁、航运中断等地缘宏观事件对化工品的传导；
- 隆众资讯、卓创资讯等产业平台的最新资讯。

## 信源原则

公开可稳定抓取的源直接使用 RSS/web_list/json_list。
隆众、卓创、期货研报和企业商机等可能涉及付费、登录、授权或内部数据的内容，默认通过 `external` 适配器推送，站内只展示允许范围内的摘要与原文链接。

## 精选门槛

`selection.ts` 暂时保留框架默认阈值。正式上线前应按 `docs/selection.md` 标注 100–200 条化工样本重新校准。


## 精细化工产品层

精细化工不靠固定产品标签穷举。固定 taxonomy 只定义稳定的产品族，例如电子化学品、医药中间体、涂料/油墨原料、橡塑助剂、表面活性剂、催化剂等。

具体产品由模型动态抽取：
- 产品名、别名、英文名；
- 原文明示的 CAS；
- 牌号/等级、纯度、规格、品牌；
- 商机动作、企业、数量/频次、地区、交付地点和截止时间。

这些结构化字段写入 analyses.output，并进入站内搜索与详情页 Site API。CAS 不允许模型凭记忆补全。
